# STARX 星选商城 · 产品范围与交付要求

> 文档类型：产品与工程交付基线  
> 适用版本：v1.0+

## 一、产品定位

STARX 星选商城是一套可部署的全渠道零售演示系统，面向品牌与渠道方提供：

- 消费者购物体验（PC 商城 + 手机 H5）
- 商家履约与商品运营（商家工作台）
- 平台账号与运营治理（平台管理端）
- 统一后端 API 与数据模型

目标是交付**可演示、可联调、可 Docker 部署**的完整交易闭环，而非单页原型。

## 二、必达能力（P0）

| 编号 | 能力域 | 要求摘要 |
|------|--------|----------|
| M01 | 账号与鉴权 | 注册/登录、JWT、买家/卖家/平台角色与权限隔离 |
| M02 | 商品与目录 | 分类、列表搜索、详情、SKU、上下架、库存 |
| M03 | 购物车与地址 | 加购改数量、地址增删改查 |
| M04 | 订单与支付 | 下单、模拟支付、发货、确认收货、取消与状态流转 |
| M05 | 运营扩展 | 收藏、评价审核、热销排行、库存预警、看板与操作日志 |
| M06 | 多端呈现 | PC 消费者端、H5、商家工作台、平台管理入口 |
| M07 | 交付工程 | Docker Compose 一键启动、健康检查、冒烟脚本 |

## 三、增强能力（P1 / 选配）

| 编号 | 能力 | 说明 |
|------|------|------|
| C01 | 高并发售罄防护 | 库存事务一致性与边界验证 |
| C02 | 订单超时自动取消 | 定时任务释放库存 |
| C03 | 推荐与个性化 | 基于浏览/购买行为的推荐说明 |
| C04 | Android 原生客户端 | 与共享后端联调的原生 App |

## 四、质量基线

| 维度 | 标准 |
|------|------|
| 功能 | 主购物路径与管理路径可完整演示 |
| 安全 | 密码不可逆存储、接口鉴权、越权不可达 |
| 性能 | 常规列表分页；关键接口可冒烟回归 |
| 工程 | 主分支可构建；环境变量与密钥不入库 |
| 文档 | 架构、接口、数据模型与运行说明与代码一致 |

## 五、协作约定（工程）

1. `main` 保持可运行、可演示。
2. 接口与表结构变更需同步设计文档与迁移脚本。
3. 合并前完成自测；破坏性变更需评审。
4. 提交信息使用 `feat` / `fix` / `refactor` / `docs` / `test` / `chore`。
