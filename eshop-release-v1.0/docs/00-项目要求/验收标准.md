# STARX 星选商城 · 交付验收清单

> 用途：上线前 / 客户演示前的功能与质量门禁

## 一、验收方式

1. **系统演示**：按主路径走通买家购物与商家履约。
2. **权限抽查**：买家 / 卖家 / 平台角色边界不可互相越权。
3. **工程抽查**：Docker 或共享后端可启动；健康检查与关键接口可用。
4. **文档抽查**：运行说明、接口与数据模型与当前代码一致。

## 二、功能清单

| 编号 | 场景 | 通过标准 |
|------|------|----------|
| F01 | 注册登录 | 可注册买家；JWT 登录后访问受保护资源 |
| F02 | 商品浏览 | 分类、搜索、列表、详情、多规格 SKU |
| F03 | 购物车 | 加购、改数量、删项、库存校验 |
| F04 | 地址 | 增删改查与默认地址 |
| F05 | 下单支付 | 下单、模拟支付成功、订单状态正确 |
| F06 | 履约 | 商家发货、买家确认收货 |
| F07 | 评价 | 收货后评价、列表展示、管理端审核 |
| F08 | 收藏与热销 | 收藏状态正确；热销榜有数据 |
| F09 | 商家工作台 | 商品/SKU、库存、订单发货、日志 |
| F10 | 平台管理 | 账号启停/角色治理可用 |
| F11 | H5 主路径 | 登录、商品、购物车、下单支付、订单 |
| F12 | 部署 | `docker compose up` 后门户与 API 可访问 |

## 三、非功能清单

| 编号 | 项 | 标准 |
|------|----|------|
| N01 | 鉴权 | 未登录不可访问受保护接口；角色越权返回 403 |
| N02 | 数据 | 演示数据足以支撑完整购物演示 |
| N03 | 密钥 | 仓库无真实 `.env`；示例与生产密钥分离 |
| N04 | 回归 | 后端测试或 API 冒烟可在交付前执行通过 |
