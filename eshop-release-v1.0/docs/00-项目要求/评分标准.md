# STARX 星选商城 · 质量与交付评估标准

> 用途：对内评估交付成熟度（功能完整度 / 工程质量 / 体验与风险），非课程计分表。

## 一、功能完整度（40%）

| 维度 | 权重 | 评估要点 |
|------|------|----------|
| 交易主路径 | 20% | 浏览→加购→下单→支付→履约是否闭环 |
| 运营与管理 | 10% | 商家发货、平台账号、评价审核、库存预警 |
| 多端一致性 | 10% | PC / H5 / 管理端关键能力对齐 |

## 二、工程质量（30%）

| 维度 | 权重 | 评估要点 |
|------|------|----------|
| 安全与权限 | 10% | 鉴权、角色隔离、敏感配置不入库 |
| 可维护性 | 10% | 模块边界清晰、迁移可追踪、接口有说明 |
| 可验证性 | 10% | 自动化测试 / 冒烟脚本可复现 |

## 三、体验与稳定性（20%）

| 维度 | 权重 | 评估要点 |
|------|------|----------|
| 交互体验 | 10% | 主流程无阻断、关键页信息架构清晰 |
| 稳定性 | 10% | 演示环境可持续运行、无致命缺陷 |

## 四、文档与交付物（10%）

| 维度 | 权重 | 评估要点 |
|------|------|----------|
| 运行与部署说明 | 5% | 第三方可按 README 启动 |
| 设计一致性 | 5% | 架构/接口/数据文档与实现匹配 |

## 五、扣分与红线

| 情况 | 处理 |
|------|------|
| 主购物路径不可用 | 功能完整度不达标 |
| 存在未鉴权的敏感写接口 | 工程质量一票否决项 |
| 仓库泄露密钥/口令 | 立即整改后方可对外交付 |
| 演示环境依赖不可复现的本机脏数据 | 交付不通过 |

## 六、成熟度分级（建议）

| 级别 | 含义 |
|------|------|
| L1 可演示 | 主路径可走通，适合对内展示 |
| L2 可联调 | 多端与后端稳定联调，冒烟通过 |
| L3 可交付 | 文档齐全、部署可复现、权限与安全达标 |
