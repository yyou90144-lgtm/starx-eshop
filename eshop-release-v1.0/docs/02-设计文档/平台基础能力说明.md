# STARX 星选商城 · 平台基础能力说明

> 原「公共基建 / 脚手架」能力说明，面向商业交付文档。

## 一、范围

平台基础能力为各业务域提供统一底座，包括：

- 工程脚手架与分层约定
- 登录鉴权与当前用户上下文
- 统一 API 响应与错误处理
- 公共前端组件与路由守卫
- 数据库初始化与迁移入口
- 多端联调与集成验证

业务域（商品、订单、用户运营等）在此底座上扩展，不重复实现鉴权与公共协议。

## 二、账号模型

`sys_user` 定义账号、密码哈希、角色与状态。业务模块可扩展资料字段，但不得擅自改变认证字段语义；若需扩展，先更新数据库设计与接口文档并提交迁移。

## 三、变更原则

1. 破坏性接口/表结构变更需评审。
2. 兼容变更同步文档与契约测试。
3. 密钥、管理员初始口令仅环境变量注入。
