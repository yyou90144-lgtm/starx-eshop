# STARX 星选商城 · 测试计划

## 一、目标

验证交易主路径、权限边界、运营能力与部署可复现性，保障演示与交付质量。

## 二、范围

| 范围 | 内容 |
|------|------|
| 功能 | 鉴权、商品、购物车、地址、订单支付、履约、评价收藏、热销、管理端 |
| 端 | PC、H5、商家、平台；Android 按需 |
| 非功能 | 鉴权安全、基础性能、部署启动 |
| 不在范围 | 真实第三方支付、真实物流轨迹 |

## 三、策略

1. **接口层**：JUnit / MockMvc 与 API 冒烟脚本覆盖主路径。
2. **端到端**：人工走通买家购物与商家发货。
3. **权限**：买家/卖家/平台交叉越权用例。
4. **回归**：发布前执行冒烟 + 关键页面抽测。

## 四、环境

| 环境 | 说明 |
|------|------|
| 本地 | 共享后端或 IDE 启动 |
| Compose | MySQL + 后端 + Nginx 前端 |
| 数据 | 种子/演示数据 + 冒烟脚本自建自毁数据 |

## 五、节奏建议

| 阶段 | 活动 |
|------|------|
| 开发中 | 模块自测 + 契约测试 |
| 集成期 | 全链路冒烟、权限回归 |
| 发布前 | 缺陷收敛、演示脚本预演 |

## 六、退出标准

- P0 功能清单无阻塞缺陷
- 冒烟脚本通过或等价手测通过
- 演示环境可持续运行 30 分钟以上无致命错误
