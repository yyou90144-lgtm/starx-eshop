# STARX 星选商城 · 交付说明

## 交付内容

- `backend/`：Spring Boot 服务、数据库迁移与自动化测试
- `frontend/`：PC 商城、平台/商家管理端、手机 H5
- `android/`：原生 Android 客户端（可选联调）
- `docs/`：需求、架构、接口与测试文档
- `scripts/`：共享后端启动/停止、API 冒烟
- `docker-compose.yml`：MySQL + 后端 + 前端编排
- `.env.example`：环境变量模板（不含真实密钥）
- `README.md`：产品说明与运行指南

## 能力范围

- 买家购物闭环：浏览、规格、加购、下单、模拟支付、订单与评价
- 商家履约：商品/SKU、库存、发货与操作日志
- 平台治理：账号与运营管理
- 多端统一主题与可 Docker 部署

## 本地启动

```powershell
Copy-Item .env.example .env
docker compose up -d --build
docker compose ps
```

- PC 商城：http://localhost:8088/pc/products
- 平台管理：http://localhost:8088/admin/login
- 商家工作台：http://localhost:8088/seller/login
- 手机 H5：http://localhost:8088/m
- 健康检查：http://localhost:8088/api/actuator/health
